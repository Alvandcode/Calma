# Audio Asset Licenses

Ambient sounds in Calma are either **procedurally generated** by `tools/generate_audio.py` (NumPy) or **user-supplied recordings** converted with `tools/import_audio.py`. Every file is downmixed to mono, resampled to 22 050 Hz, loop-crossfaded so it never clicks at the seam, and normalised to −1.5 dBFS.

## Technical Details

- Format: WAV, 16-bit PCM, mono, 22 050 Hz
- Loop points: seamless equal-power cross-fade at the boundary
- Peak normalization: −1.5 dBFS (safe for mixing up to 4 layers)

## Regeneration / replacement

```bash
# regenerate procedural sounds
python tools/generate_audio.py

# convert your own recordings (named rain.wav, forest.wav, ...)
python tools/import_audio.py path/to/my/recordings
python tools/import_audio.py --verify
```

The importer requires `ffmpeg` only for MP3/OGG/FLAC input; plain WAV works natively.

### Licensing your own files

If you replace assets with third-party recordings, replace the Source column above with the file name, author and source URL, add the licence text below, and keep a copy of the licence. CC0 / CC-BY / public domain are the safest choice for an open-source, offline-only app.
